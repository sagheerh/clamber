### Failures found and corrected

1. Dictionary assertions incorrectly required GDScript integer/float type identity
   after JSON loading. Compare both sides in the JSON domain instead; store logic
   and payload values were not changed.
2. The text-resource parser rounds the declared timestep decimal two ULPs below
   GDScript division. Permit only four relative float64 ULPs in that resource
   representation assertion; the tuning values remain unchanged.
3. Android export required explicit ETC2/ASTC import support and a fully configured
   editor SDK/JDK environment. The project and clean CI setup now provide these.
4. Bundletool prints the portrait enum numerically in its decoded manifest. The
   inspector accepts only the symbolic portrait value or its Android enum value 1,
   and still rejects landscape/other values.
